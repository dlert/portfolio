# Adeniyi Oluwaferanmi — Portfolio

Personal site for Adeniyi Oluwaferanmi, founder of Ferdar Limited.

Vite + React + TypeScript + Tailwind v4 + shadcn/ui + Motion + Lenis.

```bash
npm install
npm run dev
```

## Content
- Projects: `src/data/projects.ts` (add `repo` or `live` URLs to show Code / Live buttons)
- Experience: `src/data/experience.ts`
- Contact email: `src/components/contact.tsx` and `src/components/footer.tsx`
