# Project screenshots

Drop one image per project here using these exact filenames. Each one replaces its placeholder on the site automatically.

| Project                     | File                              |
| --------------------------- | --------------------------------- |
| Face Recognition Attendance | `face-recognition-attendance.png` |
| Daily Loop                  | `daily-loop.png`                  |
| Corporate Website           | `corporate-website.png`           |

Images are shown at a 16:10 ratio, so something like 1600×1000 works best. To use `.jpg` or `.webp` instead, change the `image` path for that project in `src/data/projects.ts`.
